## 1. The 2-Stage Loop (What Each Step Means)

For every phase `P0` … `P16` (defined in `docs/implementation-plan-detailed.md`):

| Step | Stage | Action | Spec Kit Command | Output |
|---|---|---|---|---|
| 1 | A (Refine) | Review the target phase in the master plan | `Read docs/implementation-plan-detailed.md` (relevant phase section) | Confirmed scope |
| 2 | A | Create feature spec from the phase | `/speckit-specify ...` | `specs/<NNN>-<slug>/spec.md` |
| 3 | A | Resolve ambiguity gaps (optional but recommended) | `/speckit-clarify ...` | Answers encoded back into `spec.md` |
| 4 | A | Generate detailed technical plan | `/speckit-plan ...` | `specs/<NNN>-<slug>/plan.md` |
| 5 | A | Generate atomic micro-task checklist | `/speckit-tasks ...` | `specs/<NNN>-<slug>/tasks.md` |
| 6 | A | Cross-artifact consistency check | `/speckit-analyze` | Analysis report |
| 7 | A ⟶ **HUMAN GATE** | Human lead reviews `spec.md` + `plan.md` + `tasks.md` and approves | *(manual.reply)* | ✅ approved / ❌ change requests |
| 8 | B (Implement) | Execute the phase's `tasks.md` task-by-task with verification | `/speckit-implement ...` | `[x]` tasks + passing verify |
| 9 | B | Verify zero unbuilt gaps remain before next phase | `/speckit-converge` | Convergence report |

**Hard rule (per `AGENTS.md`):** Step 8 must NOT start until Step 7 is explicitly approved by the human. Never batch-implement multiple phases.

## 3. ☎️ "What Is The Next Step?" Reply Protocol (AI Instructions)

When the human asks anything like *"what is the next step?"*, *"what now?"*, *"continue"*, *"where are we?"*:

1. **Read this file** (`temp/tools/speckit-progress.md`) — do not answer from memory.
2. Find the **first row in §2 Stage A** (top to bottom, P0 ➔ P16) that has an unchecked step (☐ in Steps 1–7).
3. Find the first unchecked column in that row — that is the next step.
4. **Reply in this exact compact format:**

```text
📍 Current position: Phase <Px> (<name>) — Stage A, Step <N>/<7>
▶️  Next step: <Step name>
    Run: <exact command the user should type>
    Context: <1–2 sentence scope of what this step produces>
⏸  Blocked by: <human approval | nothing>
```

**Special cases:**
- If the first unchecked item is **Step 7** → answer must say: *"Phase Px plan is ready for YOUR review. Read `specs/<NNN>-<slug>/spec.md`, `plan.md`, `tasks.md`, then reply 'approved' or request changes. I will not run /speckit-implement until you approve (AGENTS.md directive)."*
- If all Stage A steps are ✅ but Step 7 is pending → same as above.
- If a phase has Step 7 ✅ → next step is Stage B: `/speckit-implement` for that phase.
- If a phase has Step 9 ✅ → next step is Stage A Step 1 of the following phase (`Px+1`).
- If everything is complete (P16 converged) → declare P0 maturity done and reference `docs/PRD.md` §16 exit criteria.

## 4. ✍️ Status Update Protocol (AI Instructions — Run Automatically)

**Trigger**: Immediately after completing ANY of the 9 steps (including human approval in Step 7).

1. Mark the checkbox: change the relevant `☐` to `✅` in §2 (use the edit tool; keep other rows untouched).
2. If starting Stage B, set that phase's Final Phase Status to `🚧 Implementing`; if Step 9 ✅, set it to `✅ Complete & Converged`.
3. Update the header of this file: append the completed step to **§5 Progress Log** (one line, format below). If the step was blocked, also add an entry to **§6 Blockers & Decisions**.
4. Do **not** modify any other content in this file.
5. Confirm to the user in one line: `📝 Progress tracker updated: Phase <Px> Step <N> ✅`
