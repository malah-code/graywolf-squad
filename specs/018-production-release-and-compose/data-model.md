## 1. Production Compose Service Matrix (`docker-compose.prod.yml`)

| Service Name | Image / Build Target | Networks | Restart Policy | Key Volumes / Mounts | Depends On |
|---|---|---|---|---|---|
| `docker-proxy` | `tecnativa/docker-socket-proxy:latest` | `daemon-net` | `unless-stopped` | `/var/run/docker.sock:/var/run/docker.sock:ro` (`EXEC=0`, `VOLUMES=0`, `CONTAINERS=1`, `POST=1`, `NETWORKS=1`, `IMAGES=1`) | None |
| `postgres-shared` | `pgvector/pgvector:pg16` | `control-net` | `unless-stopped` | `graywolf_pgdata:/var/lib/postgresql/data`, `./docker/postgres/init:/docker-entrypoint-initdb.d:ro` | None |

| `db-migrate` | `docker/orchestrator/Dockerfile.prod` | `control-net` | `"no"` | None (executes `/app/scripts/db-migrate-init.sh`) | `postgres-shared` (`service_healthy`) |
| `litellm-proxy` | `ghcr.io/berriai/litellm:main-latest` | `control-net` | `unless-stopped` | `./docker/litellm/config.yaml:/app/config.yaml:ro`, `graywolf_litellm:/root/.local/share/litellm` | `postgres-shared` (`service_healthy`) |

| `dashboard` | `docker/dashboard/Dockerfile.prod` | `edge-net` | `unless-stopped` | Static Nginx assets (`/usr/share/nginx/html`) + `/etc/nginx/conf.d/default.conf` | `orchestrator` (`service_healthy`) |

## 2. Network Isolation Model (4 Segmented Networks)

| Network Name | Driver | `internal` Flag | Attached Services | Purpose |
|---|---|---|---|---|
| `edge-net` | `bridge` | `false` | `dashboard`, `orchestrator` | Public/Host browser entrypoint (ports `80`/`5173` and `3000`). |
| `control-net` | `bridge` | `true` | `postgres-shared`, `valkey`, `db-migrate`, `litellm-proxy`, `orchestrator` | Isolated control-plane bus; zero external internet or sandbox attachment. |
| `daemon-net` | `bridge` | `true` | `docker-proxy`, `orchestrator` | Private 2-member bridge shielding the Docker socket proxy. |
| `runner-net` | `bridge` | `false` | `orchestrator` (Port `3001` ARP only) + dynamic task sandboxes | Dedicated sandbox execution network with egress firewall enforcement. |

## 3. Production Environment Configuration Entity (`.env.production.example`)

| Variable | Default / Template Value | Constraint / Validation Rule |
|---|---|---|
| `NODE_ENV` | `production` | Must be `'production'` in production deployment |
| `DEPLOYMENT_TOPOLOGY` | `solo` | `'solo' \| 'team' \| 'enterprise'` |
| `PORT_CONTROL` | `3000` | Control Plane HTTP/WS port (`1024..65535`) |
| `PORT_ARP` | `3001` | Dedicated ARP WebSocket port (`1024..65535`, distinct from `PORT_CONTROL`) |
| `DASHBOARD_PORT` | `8080` | Host port mapped to Dashboard Nginx port `80` |
| `POSTGRES_USER` | `graywolf` | Non-empty PostgreSQL username |
| `POSTGRES_PASSWORD` | `CHANGE_ME_GENERATED_BY_INSTALLER` | Cryptographically random 64-char hex secret generated by `install.sh` |
| `POSTGRES_DB` | `graywolf_db` | Primary PostgreSQL database name |
| `VALKEY_MAXMEMORY` | `512mb` (`256mb` on $\le$ 8GB RAM) | Enforced with `--maxmemory-policy noeviction` |
| `MAX_CONCURRENT_CONTAINERS` | `3` (`1` on $\le$ 8GB RAM) | Hardware admission ceiling (`1..16`) |
| `CONTAINER_MEMORY_LIMIT` | `2g` | Per-sandbox container RAM limit |
| `GRAYWOLF_KEK_PATH` | `/home/graywolf/.graywolf/master.key` | Mounted from `graywolf_keys` volume (`0600` permissions) |
| `LITELLM_MASTER_KEY` | `sk-graywolf-CHANGE_ME` | Generated by `install.sh` for internal gateway auth |
| `OTEL_ENABLED` | `false` | Opt-in OpenTelemetry export (`false` by default for `$0` zero-egress runs) |
| `OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT` | `false` | Must remain `false` in Topologies B/C (fail-closed privacy rule) |
