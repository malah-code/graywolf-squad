### 1.3 `TaskArtifactRecord` (Synced to `task_artifacts` PostgreSQL table)
| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `string` (UUID) | PK | Generated by PostgreSQL `gen_random_uuid()` |
| `taskId` | `string` | `^TASK-[0-9A-Z-]+$` | Foreign key to `tasks(id)` |
| `workspaceId` | `string` (UUID) | RLS tenant key | Foreign key to `workspaces(id)` |
| `artifactType` | `string` | `VARCHAR(32)` | Artifact kind (`brief`, `plan`, `patch`, `result`, etc.) |
| `authoredBy` | `string \| null` | Optional | `'human' \| 'dev-level-1' \| 'dev-level-2' \| 'dev-level-3' \| 'orchestrator'` |
| `filePath` | `string` | Relative path | e.g., `.agents/tasks/TASK-401/brief.md` |
| `contentHash` | `string` | 64-char hex | Lowercase SHA-256 digest of file content |

## 2. Chokidar Watcher Events (`src/orchestrator/runner/task-watcher.ts`)

### 2.1 `TaskBriefChangeEvent`
- **`task.inject`** (Minor clarification):
  - Emitted after 200ms debounce when `brief.md` body or non-scope metadata changes while `writableScope`, `blockedBy`, and `targetFiles` remain identical.
  - Payload: `{ type: 'task.inject'; taskId: string; contentHash: string; body: string; frontmatter: TaskBriefFrontmatter }`
- **`task.pivot`** (Major requirement/scope pivot):
  - Emitted after 200ms debounce when `writableScope`, `blockedBy`, or `targetFiles` in `brief.md` frontmatter is modified compared to the baseline snapshot.
  - Payload: `{ type: 'task.pivot'; taskId: string; nextStatus: 'UPDATED'; contentHash: string; changedFields: string[]; frontmatter: TaskBriefFrontmatter; body: string }`

## 4. Atomic Lock Metadata (`src/orchestrator/runner/lock.ts`)

### 4.1 `TaskLockMetadata` (`.agents/locks/<TASK_ID>.lock/metadata.json` & `task_locks` table)
| Field | Type | Constraints | Description |
|---|---|---|---|
| `taskId` | `string` | PK in `task_locks` | Locked task ID |
| `workspaceId` | `string` | Optional UUID | Workspace UUID when synced to `task_locks` |
| `pid` | `number` | `process.pid` | OS process ID holding the lock |
| `containerId` | `string \| null` | Nullable | Ephemeral runner container ID (`gw-task-...`) |
| `acquiredAt` | `number` | Epoch ms (`BIGINT`) | Timestamp when lock was acquired |
| `lastHeartbeat` | `number` | Epoch ms (`BIGINT`) | Updated every 15s (`15000ms`) |
| `staleTimeoutMs` | `number` | Default `30000` | Lock lease timeout in ms (boot GC reclaims locks > `60000ms`) |

## 5. 3-Tier Sandbox Database Isolation (`src/orchestrator/db/sandbox-db.ts`)

### 5.1 `SandboxDbTier`
- `'tier-0-mock'` — No database provisioned; `connectionString: null`
- `'tier-1-shared-db'` — Per-task PostgreSQL schema `task_<sanitized_id>` with `search_path=task_<sanitized_id>,public`
- `'tier-2-isolated-db'` — Full database clone `CREATE DATABASE task_<sanitized_id> TEMPLATE graywolf_template`

### 5.2 `SandboxDbResolutionInput`
| Field | Type | Precedence |
|---|---|---|
| `explicitTier` | `SandboxDbTier \| undefined` | **1 (Highest)**: Human Task Override |
| `targetFiles` | `string[] \| undefined` | **2**: Pre-flight File Pattern Analyzer (`**/migrations/**`, `**/*.sql`, `**/schema.prisma`, `**/alembic/**`, `**/drizzle/**`) |
| `plannerDeclaredTier` | `SandboxDbTier \| undefined` | **3**: Dev-Level-1 `plan.md` declaration |
| `defaultTier` | `SandboxDbTier \| undefined` | **4 (Lowest)**: Global Config Default (fallback `'tier-0-mock'`) |
